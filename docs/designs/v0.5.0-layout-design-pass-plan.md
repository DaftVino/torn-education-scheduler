**Goal:** Implement the four owner-selected direction-C layouts from

**Architecture:** Presentation only. Existing model fields remain the source of

**Design sources:**

## Global constraints

- Never read the userscript whole. Use `docs/code-map.md` and narrow symbol
  ranges.
- Focus is closed. Do not change `renderFocusView` or its CSS.
- Course names and bonus strings come from Torn: `textContent`, never
  `innerHTML`.
- Preserve the current all-remaining banner, conditional booster rows, floor
  cost rule, Settings controls, event handlers and storage shapes.
- No panel text is black. Primary text uses `--tm-text`; secondary text uses
  `--tm-meta` or `--tm-muted`; success and error text keep their text-safe
  tokens. Never use `black`, `#000`, or a background token as a text colour.
- Inputs, selects, textareas and buttons remain explicitly light on their dark
  surfaces.
- Comparable numbers use tabular figures: finish dates, durations, costs,
  priorities and numeric inputs. This is alignment, not a new type token.
- Torn-owned course names and bonus strings must survive hostile lengths. Grid
  children get `min-width: 0`; text-bearing elements get
  `overflow-wrap: anywhere`; nothing is ellipsized or clipped.
- Secondary detail lines across Degrees, Queue and Boosters use one visual
  treatment: `--tm-meta`, `--tes-text-sm` and consistent middle-dot separators.
- Completed degree rows use `--tm-muted` while retaining the words
  `Already complete`, so colour is never the only signal and unfinished dates
  remain visually dominant.
- Read-only rows gain no extra backgrounds, alternating colours, badges,
  shadows or hover treatment. Those cues would add weight or imply interaction.
- No new colour, type or spacing token unless implementation proves an existing
  token cannot express the selected direction. If that happens, stop and amend
  the design record before adding it.
- Preserve the style-test rules: no hex outside the token block, no literal
  `px` in `font-size` or margins outside the block, no opacity, no `color-mix`,
  and `:focus-visible` rather than plain `:focus`.
- Run `npm test` and `npm run test:syntax` before completion. Regenerate
  `docs/code-map.md` after the userscript's line anchors move.
