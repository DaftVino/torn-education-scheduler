# Path Summary Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an inverted `summary` toggle after `focus` in the nav row. It opens a compact path summary (improvements, counts, time, dates) above `Queue fin:` and closes on any other control.

**Architecture:** A pure engine function, `pathGains`, totals what the queued courses deliver by calling the existing `focusTotals` per selection, so no unit, dedupe or unstatable rule is re-derived. `buildPanelModel` formats it behind the same gate as `finishLabel`. The button and block are rendered by the existing nav and Schedule renderers. The open state is closure-only in `init()`, and a `closesSummary` wrapper over the handler set closes it on every other handler.

**Tech Stack:** One IIFE in `torn-education-scheduler.user.js`. Zero dependencies. Tests are `node --test` only.

**Spec:** `docs/designs/v1.3.0-path-summary.md`. Read it before Task 1. Issue #8.

## Review Focus

Failure modes the spec implies but no obvious test exercises. Each now has a test in its owning task.

1. **A handler fired by the render itself, rather than by the player.** Through the wrapper it would close the summary the instant it opened. *Task 4: after opening, the freshly drawn panel still contains the block, and still does after an unrelated redraw (the save-failure path).*
2. **A queue edit that empties or breaks the plan while the summary is open.** The player expects it to close, and the button to go disabled rather than open an empty block. *Task 4: remove courses until the queue is empty; the block is gone and the button is disabled.*
3. **An all-remaining queue (115 courses) on a narrow PDA screen.** Long category lines must wrap inside the panel, not widen it. *Task 3: style test pins `overflow-wrap: anywhere` and `min-width: 0` on `.tes-path-summary`.*
4. **Torn changing an outcome string.** The bonus totals silently shrink. *Task 2: a catalogue with one edited outcome renders the health note.*
5. **A queue whose courses deliver no taxonomy bonus.** It must render no bonus lines and no empty header, but still the headline, dates and working stats. *Task 2: a one-course queue with no learning outcomes.*

```js
  // What a queued path delivers, per (category, selection) and never summed
  // across them: the same rule focusTotals and focusScores keep. Each figure
  // is focusTotals' own `remaining` with every course OUTSIDE the queue
  // treated as banked, so the unit rule, FOCUS_UNSTATABLE and the by-course
  // dedupe are focusTotals' rather than a second copy of them.
  // FOCUS_CATEGORIES is declared further down; it is read only when this
  // runs, long after the IIFE has initialised.
  function pathGains(queue, courses) {
    const map = (courses instanceof Map) ? courses : new Map();
    const ids = Array.isArray(queue)
      ? queue.filter(function (id, i, a) { return map.has(id) && a.indexOf(id) === i; })
      : [];
    const out = { courseCount: ids.length, degreeCount: 0, workingStats: [], categories: [] };
    if (ids.length === 0) return out;

    const queued = new Set(ids);
    const notQueued = new Set();
    for (const id of map.keys()) if (!queued.has(id)) notQueued.add(id);

    out.degreeCount = ids.filter(function (id) { return map.get(id).tier === 3; }).length;

    for (const stat of WORKING_STATS) {
      const t = focusTotals({ category: FOCUS_WORKING_STATS, selection: stat }, map, notQueued);
      if (t.remaining > 0) out.workingStats.push({ stat: stat, amount: t.remaining });
    }

    for (const category of FOCUS_CATEGORIES) {
      if (category === FOCUS_WORKING_STATS) continue;
      const selections = FOCUS_TAXONOMY
        .filter(function (r) { return r.category === category; })
        .map(function (r) { return r.selection; })
        .filter(function (s, i, a) { return a.indexOf(s) === i; });
      const gains = [];
      for (const selection of selections) {
        const t = focusTotals({ category: category, selection: selection }, map, notQueued);
        if (t.remaining > 0) gains.push({ selection: selection, unit: t.unit, amount: t.remaining });
      }
      if (gains.length === 0) continue;
      gains.sort(function (a, b) {
        const ac = a.unit === 'count' ? 1 : 0;
        const bc = b.unit === 'count' ? 1 : 0;
        if (ac !== bc) return ac - bc;
        if (!ac && a.amount !== b.amount) return b.amount - a.amount;
        return a.selection < b.selection ? -1 : a.selection > b.selection ? 1 : 0;
      });
      out.categories.push({ category: category, gains: gains });
    }
    return out;
  }
```

```js
  // The summary toggle's text, built here so the renderer only places strings.
  // Every figure is one (category, selection) or one stat. Nothing is summed
  // across them, for the reason pathGains gives.
  const PATH_SUMMARY_ITEMS_PER_LINE = 4;
  function pathSummaryModel(gains, labels) {
    const num = function (n) { return Number(n.toFixed(2)).toLocaleString('en-US'); };
    const plural = function (n, word) { return `${n} ${word}${n === 1 ? '' : 's'}`; };
    const head = [plural(gains.courseCount, 'course')];
    if (gains.degreeCount > 0) head.push(plural(gains.degreeCount, 'degree'));
    head.push(labels.totalLabel);

    let dates = `Finishes ${labels.finishLabel}`;
    if (labels.floorFinishLabel) dates += ` · Books floor ${labels.floorFinishLabel}`;

    const workingStats = gains.workingStats.length === 0 ? null
      : 'Working stats: ' + gains.workingStats.map(function (w) { return `+${num(w.amount)} ${w.stat}`; }).join(' · ');

    const categoryLines = gains.categories.map(function (c) {
      const items = c.gains.map(function (g) {
        if (g.unit === 'percent') return `${g.selection} +${num(g.amount)}%`;
        if (g.unit === 'flat') return `${g.selection} +${num(g.amount)}`;
        return g.selection;
      });
      const shown = items.slice(0, PATH_SUMMARY_ITEMS_PER_LINE);
      if (items.length > shown.length) shown.push(`+${items.length - shown.length} more`);
      return `${c.category}: ${shown.join(' · ')}`;
    });

    const h = labels.focusHealth;
    const healthNote = (h && (h.stale > 0 || h.unmapped > 0))
      ? "Some bonuses could not be matched to Torn's current course text and are not counted."
      : null;

    return { headline: head.join(' · '), dates: dates, workingStats: workingStats,
      categoryLines: categoryLines, healthNote: healthNote };
  }
```
