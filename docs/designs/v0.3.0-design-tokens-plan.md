# Design Tokens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every hardcoded value in the panel's stylesheet with a token — colour from Torn Bookie Live Scores' default scheme, plus a type scale, a spacing scale, and a focus ring.

**Architecture:** One `#tes-panel` custom-property block. Every rule references tokens. No theme switcher, no stored preference, no new feature. The visible result should be nearly no visible change, which is the evidence the refactor did what it claimed.

**Tech Stack:** One IIFE in `torn-education-scheduler.user.js`. Zero dependencies. `node --test` only.

**Spec:** `docs/designs/v0.3.0-color-tokens.md`. Read it, including the design review findings, before Task 1.

**Sequencing:** **This plan runs last.** § H3, § H4 and § H5 each add styled elements; tokenising before they land means tokenising again for each, and worse, means three specs picking hardcoded values a fourth then has to hunt down.

## Global Constraints

- **Never open `torn-education-scheduler.user.js` whole.**
- **`docs/code-map.md` updates in the same commit** as any declaration move.
- **Security surface frozen.**
- **No hex literal, `px` font size, or `px` margin outside the token block.**
- **`-text` tokens are for type; plain tokens are for fills.** Never `color: var(--tm-good)`.
- **No `font-family` anywhere.** The panel inherits Torn's font. Owner-agreed.
- **Every new function a test calls must be added to `EXPORT_NAMES` in
  `tests/load-userscript.js`, in the same commit that adds the function.**
  The userscript is one IIFE with no exports; the harness injects a global
  built from that list. A function missing from it is invisible to tests and
  the failure reads as `x.foo is not a function`, which looks like the
  function was never written. Removing a function removes its name too.
- **No attribution footers.**
- Run `npm test` and `npm run test:syntax` before every commit.

- [ ] **Step 1: Write the failing test**

```javascript
'use strict';
const { test } = require('node:test');
const assert = require('node:assert');
const { loadUserscript } = require('./load-userscript');

function css() { return loadUserscript().exports.panelStyleText(); }

function tokenBlock(text) {
  const m = /#tes-panel\s*\{([\s\S]*?)\}/.exec(text);
  return m ? m[1] : '';
}
function outsideTokenBlock(text) {
  return text.replace(/#tes-panel\s*\{[\s\S]*?\}/, '');
}

test('the token block declares every colour, type, spacing and focus token', () => {
  const block = tokenBlock(css());
  for (const name of ['--tm-bg', '--tm-border-2', '--tm-text', '--tm-muted', '--tm-meta',
    '--tm-good-text', '--tm-bad-text', '--tes-text', '--tes-text-sm',
    '--tes-gap', '--tes-gap-lg', '--tes-focus-ring']) {
    assert.ok(block.includes(name), `missing token ${name}`);
  }
});

test('no hex literal survives outside the token block', () => {
  const found = outsideTokenBlock(css()).match(/#[0-9a-fA-F]{3,8}\b/g) || [];
  const real = found.filter((h) => !/^#tes/.test(h));
  assert.deepStrictEqual(real, [], `hex literals outside the token block: ${real.join(', ')}`);
});

test('every declared token is referenced, and every referenced token is declared', () => {
  const text = css();
  const declared = new Set((tokenBlock(text).match(/--[a-z0-9-]+(?=\s*:)/g) || []));
  const used = new Set((text.match(/var\((--[a-z0-9-]+)\)/g) || []).map((s) => s.slice(4, -1)));
  for (const d of declared) assert.ok(used.has(d), `token ${d} is declared but never used`);
  for (const u of used) assert.ok(declared.has(u), `token ${u} is used but never declared`);
});

test('the token block is scoped to the panel and leaks nothing to :root', () => {
  assert.ok(!/:root/.test(css()), 'the panel must not declare variables on Torn\'s page');
});

test('no font-family is declared anywhere', () => {
  assert.ok(!/font-family/.test(css()),
    'the panel inherits Torn\'s font — this is a decision, not an omission');
});

test('color-mix is not used', () => {
  assert.ok(!/color-mix\(/.test(css()));
});
```

- [ ] **Step 3: Rewrite the rules**

Mechanical, per the spec's mapping table. `#1c1c1c` → `var(--tm-bg)`, `#4a4a4a` → `var(--tm-border-2)`, `#e6e6e6` → `var(--tm-text)`, `#2e2e2e` → `var(--tm-hover)`, `#7ee081` → `var(--tm-good-text)`, `#ff8080` → `var(--tm-bad-text)`, `#111` → `var(--tm-bg-3)`.

Then the four opacity rules:

| Rule | Was | Becomes |
| --- | --- | --- |
| `.tes-section-title` | `opacity: 0.85` | `color: var(--tm-meta)` |
| `.tes-note` | `opacity: 0.75` | `color: var(--tm-muted)` |
| `.tes-cell-detail` | `opacity: 0.85` | `color: var(--tm-meta)` |
| `.tes-foot` | `opacity: 0.7` | `color: var(--tm-muted)` |

Then sizes and spacing: panel `font-size: var(--tes-text)`; `.tes-finish` `var(--tes-text-lg)`; `.tes-note`, `.tes-cell-detail`, `.tes-foot`, `.tes-queue-bonus` `var(--tes-text-sm)`; every `margin-bottom: 8px` → `var(--tes-gap)`; `.tes-section` → `margin-bottom: var(--tes-gap-lg)`.

**`--tes-gap-lg` on `.tes-section` is the single change that does the most work.** Sections currently sit the same distance apart as the rows inside them, so nothing groups.

### Task 4: Contrast, computed not asserted

**Files:**
- Modify: `tests/style.test.js`
- Modify: `docs/code-map.md`

- [ ] **Step 1: Write the test**

```javascript
function ratio(hexA, hexB) {
  const lin = (c) => { c /= 255; return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4); };
  const L = (h) => {
    const n = parseInt(h.slice(1), 16);
    return 0.2126 * lin((n >> 16) & 255) + 0.7152 * lin((n >> 8) & 255) + 0.0722 * lin(n & 255);
  };
  const [hi, lo] = L(hexA) > L(hexB) ? [L(hexA), L(hexB)] : [L(hexB), L(hexA)];
  return (hi + 0.05) / (lo + 0.05);
}

test('every -text token clears WCAG AA against the panel background', () => {
  const block = tokenBlock(css());
  const val = (name) => (new RegExp(`${name}\\s*:\\s*(#[0-9a-fA-F]{3,6})`).exec(block) || [])[1];
  const bg = val('--tm-bg');
  for (const name of ['--tm-text', '--tm-muted', '--tm-meta', '--tm-good-text', '--tm-bad-text']) {
    const r = ratio(val(name), bg);
    assert.ok(r >= 4.5, `${name} is ${r.toFixed(2)}:1 against --tm-bg, below AA's 4.5:1`);
  }
});

test('the fill tokens are NOT safe as text, which is why -text exists', () => {
  const block = tokenBlock(css());
  const val = (name) => (new RegExp(`${name}\\s*:\\s*(#[0-9a-fA-F]{3,6})`).exec(block) || [])[1];
  assert.ok(ratio(val('--tm-good'), val('--tm-bg')) < 4.5,
    'if --tm-good ever passes, the -text split may be reconsidered deliberately');
});
```

The ratio is **computed in the test**, never hardcoded — a hardcoded expectation would let a token change silently break the thing the test protects.
