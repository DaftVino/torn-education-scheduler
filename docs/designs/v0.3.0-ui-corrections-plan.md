# UI Corrections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eight presentation corrections to the panel: a permanent settings landmark, ISO dates with Torn time shown separately, compact wording, per-course bonuses in queue rows, a real header button, an all-remaining banner, a structured summary, and green bachelor options.

**Architecture:** Presentation only. No scheduling logic, stored data, permission or network change. Two renderers gain structure (`.tes-header`, `.tes-summary`); one formatter splits in two; one formatter abbreviates.

**Tech Stack:** One IIFE in `torn-education-scheduler.user.js`. Zero dependencies. `node --test` only.

**Spec:** `docs/designs/v0.3.0-ui-corrections.md`. Read it, including both owner decisions, before Task 1.

**Sequencing:** **Task 5 requires § H3** (`FOCUS_TAXONOMY`, `workingStatsFor`). Every other task is independent. Run 1–4 and 6–9 in any order; run 5 after focus mode lands.

## Global Constraints

- **Never open `torn-education-scheduler.user.js` whole.** Grep `docs/code-map.md`, then `Read` with `offset`/`limit`.
- **`docs/code-map.md` updates in the same commit** as any declaration move. `tests/code-map.test.js` enforces ranges, symbols, line counts, per-file test counts.
- **Security surface frozen.** One `@match`, `GM_setValue`/`GM_getValue`, no `@connect`.
- **Course names are never trusted into markup.** `textContent` everywhere, never `innerHTML`.
- **Every new DOM lookup gets a null guard and a visible failure path.**
- **Dates use UTC getters, never local.** Torn City Time is UTC+0.
- **Every new function a test calls must be added to `EXPORT_NAMES` in
  `tests/load-userscript.js`, in the same commit that adds the function.**
  The userscript is one IIFE with no exports; the harness injects a global
  built from that list. A function missing from it is invisible to tests and
  the failure reads as `x.foo is not a function`, which looks like the
  function was never written. Removing a function removes its name too.
- **No attribution footers.**
- Run `npm test` and `npm run test:syntax` before every commit.

```javascript
  // Torn City Time is UTC+0, so these are the UTC getters and the instant is
  // unchanged from the old toUTCString(). What changed is that the date and the
  // time are separate values and the label says TCT — which is what the rest of
  // the player's screen says while they read this.
  //
  // NEVER the local getters. A player on UTC+10 reading a bare local 21:00
  // would be eleven hours wrong about when to log in, and the bug is invisible
  // on any machine already set to UTC, including CI. tests/engine.test.js pins
  // a non-UTC TZ for exactly that reason.
  function pad2(n) { return n < 10 ? `0${n}` : String(n); }

  function formatDate(seconds) {
    const d = new Date(seconds * 1000);
    return `${d.getUTCFullYear()}-${pad2(d.getUTCMonth() + 1)}-${pad2(d.getUTCDate())}`;
  }

  // No seconds: a finish estimate derived from course durations is not accurate
  // to the second, and a ":00" that never varies claims precision it lacks.
  function formatTime(seconds) {
    const d = new Date(seconds * 1000);
    return `${pad2(d.getUTCHours())}:${pad2(d.getUTCMinutes())}`;
  }
```

```javascript
  // What a course actually gives, from the two payload fields that say so.
  // Never inferred from a name: 31 of 131 courses list no outcome at all, and
  // "Bonus: not listed by Torn" is the honest answer for them — the same trade
  // the panel makes with a withheld finish date.
  function bonusLabel(course) {
    const stats = workingStatsFor(course);
    const parts = [];
    for (const [stat, n] of stats) parts.push(`${n} ${stat}`);
    const outcomes = (course && Array.isArray(course.learningOutcomes)) ? course.learningOutcomes : [];
    for (const o of outcomes) if (typeof o === 'string') parts.push(o);
    if (parts.length === 0) return 'Bonus: not listed by Torn';
    if (outcomes.length === 0) return `${parts.join(', ')} · other bonus not listed by Torn`;
    return parts.join(' · ');
  }
```
